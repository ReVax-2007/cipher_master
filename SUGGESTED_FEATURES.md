# 💡 Suggested Features

This document details new functional capabilities and user-facing features proposed for future versions of **Cipher Master**.

---

## 1. Core Cipher & Engine Expansion
* **New Ciphers**:
  * **Playfair Cipher**: Digraph substitution using a 5x5 key matrix.
  * **Enigma Machine Emulator**: Multi-rotor simulation with configurable reflector settings.
  * **Baconian Cipher**: Steganographic binary substitution ($A/B$ character mapping).
  * **Columnar Transposition**: Multi-stage keyed matrix transposition.
* **Multi-Stage / Chained Encryption**: Allow users to stack multiple ciphers sequentially (e.g., Caesar Shift followed by Rail Fence).

## 2. Interactive GUI & User Experience
* **Built-in Decryption Workspace**: Interactive scratchpad inside the application window with frequency analysis charts, letter counts, and live decoding textboxes.
* **Interactive Runes Map**: Clickable Elder Futhark keyboard/reference panel for visual translation.
* **Custom Output Paths**: Allow users to select custom output folders instead of defaulting strictly to the Desktop directory.

## 3. Game & Challenge Modes
* **Timed Challenge Mode**: In-app countdown timer with a scoring metric based on completion speed and hint usage.
* **Custom Quote Input**: GUI text field allowing users to input their own custom plaintext passage directly before generating files.
